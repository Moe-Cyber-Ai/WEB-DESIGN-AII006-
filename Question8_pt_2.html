Website Evaluation and Analysis

1. Appealing Website — Netflix

a. What is the URL of the website?
https://www.netflix.com

b. Does this page use tables?
No, Netflix does not visibly use tables. The website mainly uses modern layouts to organize movies and shows.

c. Does this page use CSS?
Yes, Netflix uses CSS for page layout, colors, animations, buttons, spacing, and responsive design.

d. Is this page appealing or unappealing?
This page is appealing for these reasons:

  • The design looks modern and professional.
  • The red, black, and white colors look attractive.
  • The website is easy to navigate and use.

2. Unappealing Website — Hollywood Movie Websites in the 2000s

a. What is the URL of the website?
https://www.webdesignmuseum.org/exhibitions/hollywood-movies-websites-in-the-00s

b. Does this page use tables?
Some old movie websites shown in the article used tables for page layout and organizing content.

c. Does this page use CSS?
Yes, CSS is used for text styles, colors, layout, and page formatting.

d. Is this page appealing or unappealing?
The old movie website designs are unappealing for these reasons:

  • The pages look crowded and messy.
  • Too many bright colors and graphics are used.
  • The navigation is confusing and difficult.

e. If this page is unappealing, what would you do to improve it?

  • Use a cleaner and simpler layout.
  • Add more spacing between sections.
  • Use fewer colors and modern fonts.
