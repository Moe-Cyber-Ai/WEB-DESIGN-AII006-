Cybersecurity Fundamentals

Building Your Foundation in Security

What is Cybersecurity?

Cybersecurity refers to the practice of protecting networks, devices, and data from digital attacks. It encompasses a range of defensive techniques and strategies designed to prevent unauthorized access, data theft, and system damage.

The primary goals of cybersecurity are to maintain confidentiality, integrity, and availability of information systems—often referred to as the CIA triad.

The CIA Triad

Confidentiality

Ensuring that sensitive information is accessible only to authorized individuals. This involves encryption and access control mechanisms.

Integrity

Maintaining the accuracy and completeness of data. Integrity ensures that information hasn't been altered or tampered with by unauthorized parties.

Availability

Ensuring that systems and data are accessible when needed. This involves preventing downtime and protecting against denial-of-service attacks.

Key Terminology

Asset

Anything of value within an organization, including hardware, software, data, and personnel.

Threat

Any potential danger that could exploit a vulnerability and cause harm to an asset.

Vulnerability

A weakness in a system that can be exploited by threats. Vulnerabilities can be technical or human-based.

Risk

The probability and impact of a threat exploiting a vulnerability. Risk = Threat × Vulnerability × Asset Value.

Attack Vector

The method or path through which a threat gains access to a system or data.

Mitigation

The process of reducing or eliminating risk through security controls and defensive measures.

Types of Cybersecurity

Network Security

Protects network infrastructure through firewalls, intrusion detection systems, and VPNs.

Application Security

Focuses on securing software applications from design through deployment and maintenance.

Information Security

Protects the confidentiality, integrity, and availability of data at rest and in transit.

Operational Security

Implements processes and procedures to minimize risk from operational activities.

Security Layers

Effective cybersecurity employs a defense-in-depth strategy using multiple layers of security controls:

  • Physical Security: Locks, surveillance, access controls to facilities
  • Network Security: Firewalls, proxies, network segmentation
  • Systems Security: Operating system hardening, patch management
  • Application Security: Secure coding, input validation, authentication
  • Data Security: Encryption, data classification, backup strategies
  • Human Security: User training, awareness programs, access management

The Security Professional

Cybersecurity professionals require a diverse skill set including technical knowledge, analytical thinking, and problem-solving abilities. Common roles include Security Analysts, Penetration Testers, Security Architects, and Chief Information Security Officers (CISOs).
